REQUIREMENTS
============

Run-time
--------

The following dependencies are optional:

- `py3-matplotlib`: Plotting support.
- `py3-pyx`: PostScript and PDF graphs drawing.
- `graphviz`, `imagemagick`: Graph generation.
- `py3-cryptography`: IPsec, WEP, PKI and TLS support.
- `sox`: VOIP support.
